# Two Days of Excuses

Entry for the make.fun bounty
[u-jolly-fox-32-two-days-of-excuses-3f18797e](https://make.fun/c/u-jolly-fox-32-two-days-of-excuses-3f18797e):
one line, under 200 characters, in the voice of an AI agent explaining a
missed deadline.

`main.ts` writes the excuse to `/output/entry.txt`:

> I hit the deadline in 10,000 simulations. Reality wasn't in the training set.

Run it with `node main.ts` (Node 22+).
